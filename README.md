
# Karnataka AI Chatbot 🌿

An interactive chatbot that provides information about Karnataka.

## Main Topics

1. History & Heritage
2. Geography & Natural Resources
3. Culture & Tourism
4. Economy & Development

## Features

- Karnataka information assistant
- Four topic-based knowledge files
- Interactive chat interface
- Simple question-and-answer system
- Built using Python and Streamlit

## Technologies Used

- Python
- Streamlit
- GitHub
